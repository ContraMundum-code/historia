## 纪年与事件粒度

只收有动作、可确认年份、能对齐具体人物的内容。任官罗列、无年品评、把父子经历当成本人经历均不收。
每个新增事件都留连续原文摘句和 manifest 卷次，允许从同篇上下文解释，但不修改原语料。

- 颜师古撰五礼：段首为贞观七年，成书明载十一年，故成书事件为637年，不取633年。
- 令狐楚任命被追还：长庆元年后接二年十一月，取822年，不取段首821年。
- 李梦阳上书：弘治六年之后的十八年是1505年，不把后文奏疏系于1493年。
- 文震孟、姚希孟的三年分别承接崇祯元年，取1630年。
- 郭子仪泾阳交涉：记录永泰元年765年；五月是出镇锚点，八月入寇后才有交涉，故不把五月写成会见月份。
- 吕温出使：804年出发，805年被留，806年返唐。事件年份取出发之年，描述明确区分后续年份。

一项跨年行动可以说明后续结果，但主年份对应标题指定的具体动作，不把多年故事都写为同年发生。
同名同年的事件按键去重，另检查内容是否与首批重复，不将一次事件换名再录一遍。

## 参与者与缺ID

不按引文中出现的所有姓名自动建参与者。例如杨一清被比作郭子仪，不把已经去世的郭子仪当作当事人；
文震孟传提到姚希孟亲属关系，也不直接据此判姚希孟参与该次奏议。

帝、上、朕结合年号、月份及同篇本纪对齐。元和十五年十一月的赗赠诏对齐穆宗，
不能因年号还是元和就误归已经在正月去世的宪宗。罗伦谏起复的李贤对齐明代29603，
巴州自杀的章怀太子对齐唐代92959。章懋传中的庄昹，用庄昶本传记同疏谏张灯交叉确认ID。

主角是叙述中心，每事件仅一位。其他角色限有来源支撑者；库外人物保留姓名/称号，
不建空ID、0或虚构ID。称号尚未消歧时保留原称谓，不擅补具体姓名或扩大人物库。

外部来源明确标注为外部，摘句统一转写简体：

实际链接、摘句与判断理由见来源索引。馆藏小传、书目著录与古籍正文分别注明，不混称为 corpus 原文。

## 校验与审核

```text
python scripts/annotations/deriveCategory.py --help
python scripts/annotations/secondHalf/deriveCategory.py
python scripts/annotations/secondHalf/checkSupplement.py --base-ref origin/main
python scripts/annotations/checkAnnotations.py
python scripts/annotations/secondHalf/test_identity_review.py
```

根目录推导脚本只用于了解前半组用法，不要无名单直接重跑覆盖两组补充标签。
后半组生成器保留前半组行，缺身份依据时报错，超过4条也报错，不自动占位或静默截断。
更新本批身份后应同步对账及增改索引，再运行检查。

新增检查覆盖表头及BOM、列数、原文逐字存在性、卷次、事件去重、角色和ID、主角范围、参与者生卒、
身份覆盖与上限、来源索引、生成一致性及187人对账；与基线对比时确认原有事件、前半组身份和受保护文件未改。
回归测试覆盖自动占位禁用、赠官/异常日期排除、官职不能借给另一人、表头与引文转义和四标签上限。

全局检查虽提示C测试集为空时通过，本批不把它算作有效的C隔离验证。
脚本只能检查格式及证据存在性，历史纪年、代词消歧和外部引文仍须组长沿出处审核。
不执行数据库导入，不调用PR合并接口。
