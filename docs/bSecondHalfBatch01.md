# B 阶段后半段：王雨杉首批标注

按 `person.csv` 的 `person_id` 数值升序，胡豪负责前 187 人（13–16504）；
本批只负责后 187 人（17527–189264，从吴儆到李恒）。不包含前半组身份记录。
这是替代旧 PR #4 的独立提交，目标分支为小组仓库 main，由组长审核后决定合并。

## 交付范围

- `personCategory.csv`：后 187 人的身份初标，每人至少一条，不能确认的暂标“其他”。
- `event.csv`：李揆、独孤郁、令狐楚、郑余庆、刘禹锡共 5 个事件样例，均属于后半组。
- `eventParticipant.csv`：6 条记录，全部引用现有人物 ID。
- `bEventEvidence.csv`：各事件纪年承接、换算和地点依据。
- `bReview.csv`：缺失、异常和所有“其他”身份的逐人复核记录。

所有 CSV 使用简体，保留三张原有表的英文表头，数据库、词典和原始语料均不修改。
事件采集仅完成首批 5 例，身份也是待组长审核的初标，不表示后半段任务已经全部完成。

## 身份与缺失处理

官职规则完整匹配，排除赠官、检校、致仕及任职年份与生卒冲突的行。
宰相同时标政治家；明代大学士不标宰相。中书令可能是虚衔，本批不自动判相。
不根据翰林学士直接推文学家，不把节度使掌书记或武散阶判成将领。
规则仍需检查具体人物是否实际任职。

补充判断使用本传本人证据，排除父子、其他人物、引用《诗经》或获赐他人文集的误命中。
这些判断由 AI 辅助阅读，尚需同学人工终审。`manual/1.0` 沿用现有字段约定，
不表示已经人工确认或准确率为 100%。没有可靠依据时标“其他”，并逐人列入复核表；
“其他”只是待确认占位，不表示此人没有其他身份。

| 缺失或异常 | 处理 |
|---|---|
| 地点未明载 | 留空，不用贬任目的地冒充案发地 |
| 相对纪年 | 明确承接同篇年号，在证据表说明；不能确认则不录事件 |
| 年份不明 | 进入复核表，不猜测年份 |
| 有姓名但人物库无 ID | 不写空 ID、0 或虚构 ID，登记姓名，待组长决定是否扩库 |
| 同列等未具名者 | 不建虚构人物 |
| 身份不能确认 | 暂标其他并列入复核表，后续补证据后替换 |
| 官职日期异常 | 不作推导证据，保留原数据，交组长另行校对 |

缺 ID 人物包括吐突承璀、韦正牧、于翬、裴度；参与者表暂不是完整人物名单。
刘禹锡事件中的宪宗对齐现有 ID 166933。郑余庆的司徒记录 first_year=728 早于生年 746，已排除。
郑余庆事件的两京国子监表示奏修对象所在地，不表示上奏地点；若 location 仅指行为发生地，可审核后留空。

## 与前半组协作

本批脚本与规则放在 `scripts/annotations/secondHalf/`，避免覆盖胡豪 PR 中的同名工具。
三张交付主表沿用项目统一路径，合并两份 PR 时应按行保留两组数据，不能整表替换。
身份按 person_id、category_name 去重；事件按 event_name、year 跨传去重，参与者按事件和 person_id 去重。
如果两个 PR 都从只有表头的 main 修改主表，合并可能出现 CSV 冲突，需要保留双方的有效数据。

运行方式（Python 标准库，无新增项目依赖）：

```text
python scripts/annotations/secondHalf/deriveCategory.py
python scripts/annotations/secondHalf/checkAnnotations.py
```

生成脚本只替换后半组身份，并保留已合并的前半组身份行；更新后半组时，先将新的人工判断
合入本目录的 `manualCategories.csv` 再生成，避免覆盖未进入补充表的新判断。
检查只针对本批的 5 个事件和后 187 人，允许合并后前半组数据共存。
验证表头、列数、重复项、ID、词表、身份覆盖、描述长度、证据存在性、生卒、复核清单和可重复生成结果。
历史判断仍需人工审核；本批不执行 C 测试集隔离检查或任何数据库导入。

数据库种子中的身份词表是否包含“其他”需组长在入库前确认，本 PR 不改 SQL。
下一批优先处理身份复核清单，并继续采集后半组事件，按批次记录新增量。
